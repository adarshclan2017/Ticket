# Support Desk Ticketing System

A premium, high-fidelity React application for managing technical support incidents.

## Features
- **Sidebar Navigation**: Dashboard, Tickets, Recent Records, Analytics, and Settings.
- **Incident Reporting**: Core incident details form with real-time state management.
- **Technical Provisioning**: Advanced configuration modal for system environment setup.
- **Premium UI**: Dark mode, glassmorphism, and Framer Motion animations.
- **Font Awesome Integration**: High-quality class-based icons.

## Tech Stack
- React 19
- Vite
- Framer Motion
- Font Awesome
- Vanilla CSS

## Getting Started
1. `npm install`
2. `npm run dev`
